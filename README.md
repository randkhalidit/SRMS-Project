# Student Record Management System - Qassim University
Console-based Java system for Qassim University demonstrating OOP, file management, and multithreading.

## Team Roles
* **Role 1 (Rand):** Developed core structure (Person.java, Student.java, SRMS.java).
* **Role 2 (Ghadeer):** Handled storage and concurrency (StudentFileManager.java, AutoSaveThread.java).
* **Role 3 (Salwa):** Programmed search reports (GPA, department, year) and managed GitHub.


## OOP Principles Applied
* **Inheritance:** Student extends Person.
* **Encapsulation:** Private fields with getters and setters.
* **Polymorphism:** Overridden displayInfo() method.
* **Composition:** SRMS class contains a List of Students.
* **Multithreading:** Asynchronous 30-second background auto-save.
